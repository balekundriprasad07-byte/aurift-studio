# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Aurift Studio, please do not open a public GitHub Issue containing sensitive details.

Instead, report the issue privately to the repository maintainer.

Please include:

- A description of the vulnerability
- Steps to reproduce it
- The affected file or feature
- The potential impact
- Any suggested fix, if known

Reports will be reviewed as soon as possible.

## Supported Versions

The latest released version of Aurift Studio is the actively maintained version.

Older versions may not receive security fixes.

## Scope

Security reports may include issues related to:

- Client-side JavaScript
- Third-party dependencies
- Three.js/WebGL usage
- Unsafe links or redirects
- Cross-site scripting risks
- Sensitive information accidentally committed to the repository

## Responsible Disclosure

Please allow reasonable time for a reported vulnerability to be reviewed and fixed before sharing details publicly.
