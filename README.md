# AURIFT°

AURIFT° is an open-source experimental digital studio website focused on cinematic, interaction-led web experiences.

The project explores how motion, typography, WebGL and modern frontend techniques can be combined to create immersive brand experiences without relying on a large frontend framework.

## Live Demo

https://aurift-studio.netlify.app

## Features

- Cinematic interactive landing page
- Three.js / WebGL hero experience
- Responsive desktop and mobile design
- Scroll-based interactions
- Cursor and pointer effects
- Reduced-motion support
- Keyboard navigation improvements
- Accessibility-focused focus states
- Mobile performance optimizations
- Optimized Three.js rendering
- EMBER° restaurant concept
- FORGE° fitness concept

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Three.js
- WebGL
- Google Fonts

No frontend framework or build system is required.
